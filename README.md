# kourovka-notebook-problem-21.106

We resolve a problem posed in `Unsolved Problems in Group Theory. The Kourovka Notebook`, which has arXiv link https://arxiv.org/abs/1401.0300.

Problem 21.106, posed by M. Petschick, asks the following:

A first order formula `φ(x)` in the group language with one free variable is
said to be "concise" in a class `C` of groups if for every group `G` in `C` such that the set `G_φ` of elements in `G` satisfying `φ` is finite, the subgroup `φ(G)` generated by `G_φ` is also finite (cf. 21.105 and Archive 2.45). Is every formula with one free variable concise in the class of residually finite groups?

Our answer to this question is no, and we provide a counterexample of a formula with one free variable and residually finite group pair violating the affirmative statement.

They are defined as follows:

Define the centrality predicate
`Cent(y) = ∀t (yt=ty)`.
The formula is
`φ(x) := ∃ab ([a,b]=x  ∧  ∀y (Cent(y)  ⇒  ∃cd ([a,c]=y ∧ [b,c]=1 ∧ [b,d]=y ∧ [a,d]=1)))`.
The group is simply the Heisenberg group, which is `G = ℤ^3` endowed with multiplication
`(p,q,r)(s,t,u) = (p+s, q+t, r+u+pt)`.

We plan to publish a human-readable preprint of the proof of this counterexample on arXiv.
